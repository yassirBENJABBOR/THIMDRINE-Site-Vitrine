# THIMDRINE-Site-Vitrine
Site vitrine de la coopérative Thimdrine du Rif, présentant ses produits artisanaux et permettant aux clients d'envoyer des demandes de commande.
Une coopérative du Rif regroupant 25 femmes de la région de Nador.

## Produits
- Miel de thym
- Huile d'olive
- Confiture de figue de barbarie

- CSS3
